## 0. 文档说明

### 0.1 目的与范围

本文档定义协作多维表格**前端**的完整行为需求：覆盖 P0 全部功能的页面结构、交互规格、协作行为、权限呈现、非功能指标与验收清单；P1 能力仅保留骨架章节（第 8 章），本期不实现、无验收标准。本文档不含：视觉像素规范、组件实现设计（props/状态机）、CI/CD 与代码规范（另行成文）。

### 0.2 与上游文档的关系

- 产品行为以《产品需求文档-v1.3》为准；HTTP/WS 契约以《接口文档-v0.6》为准；本文档不做接口设计，契约缺失之处统一列入第 7 章缺口清单。
- 对应关系：《前端需求文档》第 4 章标准化 PRD 第 5 章 FR-01~FR-12 的前端呈现；第 5 章落实 PRD 4.2/4.4 权限矩阵到 UI 态。
- 本文档对 PRD / 前端决策的明确差异列于 0.4，其余全部对齐。

### 0.3 技术栈约束

React 18 + TypeScript + Vite；表格网格采用**自研渲染层**（虚拟滚动 + 单元格渲染器），不引入成熟表格引擎（见 ADR 0001）；视图数据采用**游标窗口按需加载 + 断线本地队列重放**（见 ADR 0002）。所有状态管理、路由、构建工具的选型不属需求范围，由前端设计方案决定。

### 0.4 与《产品需求文档-v1.3》的差异清单（FS）

## 1. 产品定位与目标用户

### 1.1 目标用户

| 用户 | 常任角色 | 核心诉求 |
|---|---|---|
| 业务搭建者 / 团队负责人 | 可管理 | 快速搭建业务表、控制谁能看改、汇总查看 |
| 团队执行成员 | 可编辑 | 高效录入与更新，收到协作提醒 |
| 外部填报者（客户/供应商） | 可填写 / 可查看（链接） | 轻量账号登录，通过链接填报或查看指定内容 |

### 1.2 P0 交付边界

P0 交付：用户名+密码账号体系、单企业工作空间、多维表格（Base）、多数据表、11 种字段、表格视图（多视图 + 筛选/排序/分组/显隐/冻结/行高）、记录增删改、实时协作（存在感 + 冲突处理 + 离线排队）、记录级评论与 @、站内通知中心、四级角色与链接分享、操作历史与回滚、导入（.xlsx/.csv）与当前视图导出、移动端只读。

明确不做（本期与 P1 均不含）：手机号/邮箱注册登录、第三方登录、站外通知、验证码、多企业切换、原生 App、私有化交付。P1 能力见第 8 章。

## 2. 信息架构与导航

### 2.1 页面与路由清单

| 页面 | 路由形态 | 说明 |
|---|---|---|
| 登录 | `/login` | 用户名 + 密码；含试运行声明 |
| 注册 | `/register` | 三条归属路径（企业邀请 / 有效链接注册 / 直接注册即建企业） |
| 链接跳转 | `/s/{link_token}` | 重定向至 Base 或登录 / 注册页；未开放注册期间未登录访问提示「当前未开放新注册」 |
| 首页 | `/home` | 内部成员与外部账号两种形态（见 2.2） |
| 企业设置 | 首页内嵌页面 | 成员管理、操作审计、开放外链清单（仅所有者/管理员） |
| Base 工作台 | `/base/{id}` | 本文档主体页面 |
| 无权限页 | 独立渲染态 | 「你没有访问该表格的权限」+ 复制申请人信息按钮 |
| 链接失效页 | 独立渲染态 | 「链接已失效」/「表格已被删除」 |

### 2.2 导航层级

```text
未登录
 └─ 登录 / 注册 / 链接跳转页

已登录 ─┬─ 外部账号（无企业归属/其他企业）
        │    └─ 外部首页：与我共享 + 待处理企业邀请 + 通知中心（不可新建 Base）
        └─ 本企业成员
             └─ 企业工作空间首页：最近访问 / 我创建的 / 与我共享（星标置顶）
                  ├─ 企业管理后台：成员、邀请、操作审计、开放外链清单（所有者/管理员）
                  └─ Base 工作台 /base/{id}
                       ├─ 数据表标签页（Table A / Table B / +）
                       │    ├─ 视图标签页（视图1 / 视图2 / +）+ 工具栏（筛选/排序/分组/显隐/搜索）
                       │    ├─ 网格（分组行 / 记录行）
                       │    ├─ 记录详情抽屉（字段 + 评论/动态）
                       │    └─ 分享与权限弹窗
                       └─ 通知中心（全局铃铛，跨页面可用）
```

### 2.3 全局元素

| 元素 | 位置 | 行为摘要 |
|---|---|---|
| 保存状态指示 | 顶栏 | 保存中… / 已保存 / 离线未同步（见 3.8.5） |
| 在线协作者头像组 | 顶栏（Base 内） | 含外部协作者身份标签；每位成员专属颜色 |
| 通知铃铛 | 顶栏全局 | 未读红点 + 计数；见 4.8 |

## 3. 核心页面交互规格

### 3.1 首页

- 内部首页：聚合「最近访问 / 我创建的 / 与我共享（含星标置顶）」（H-21）；顶部搜索 Base 名称（H-22）；「新建多维表格」按钮（H-23）；企业邀请待办入口。
- 外部首页：仅「与我共享」+ 待处理企业邀请 + 通知中心 + 邀请接受/拒绝操作（H-13~H-15）；不提供任何新建入口。
- 空态：「与我共享为空」时展示引导文案，不堆砌功能入口。
- 固定展示试运行免责声明：「个人试运行产品，不保证服务持续与数据留存，重要数据请自行导出备份」。

### 3.2 Base 工作台（五段式布局）

```text
┌──────────────────────────────────────────────────────────┐
│ [Base 名称]  保存状态    [在线头像组(外部标签区分)] [分享] [更多▾] │ 顶栏
├──────────────────────────────────────────────────────────┤
│ 数据表: 表1 ▾  表2  +       │ 视图: 视图1 ▾ 视图2 +  [筛选 排序 分组 显隐] │ 表/视图栏
├──────────────────────────────────────────────────────────┤
│ ☐ │主字段（冻结）│ 字段A │ 字段B │ ...                    │ 网格
│   │ REC-001     │       │       │                        │
│   └─ 分组行（组名 + 记录数，可折叠）                      │
├──────────────────────────────────────────────────────────┤
│ [+ 新增记录]                       [记录数 / 已选 n 条]   │ 底栏
└──────────────────────────────────────────────────────────┘
```

- 顶栏「更多」：重命名、复制、删除（强提示「删除后不可恢复」）、星级切换；导入/导出入口见 4.11（导出仅内部可管理/可编辑可见）。
- 数据表标签页：显示未保存修改微状态；管理操作见 4.3。
- 视图栏 + 工具栏：筛选/排序/分组/字段显隐按钮显示已启用条件数徽标；「Ctrl+F」呼出视图内搜索。
- 网格：「表格」指网格控件本身（GLOSSARY）；加载与滚动模型见 ADR 0002。
- 底栏：左「+ 新增记录」；右展示当前视图记录数与已选记录数（选中多行时出现批量操作条，含删除/复制记录）。
- 首行幽灵行 `[前端增强]`：网格顶部常驻一键快速录入行，与底栏按钮共享同一提交流程。

### 3.3 记录详情抽屉

- 点击行首展开按钮打开**右侧抽屉**（宽度约 480px，可遮罩不遮挡网格交互）：
  - 主字段值（可编辑）置于顶部标题位；
  - 字段区：按字段顺序展示并可编辑**全部字段**，含当前视图隐藏字段；公式/引用字段只读展示并标注；
  - 底部「评论 / 动态」双标签页：评论对应 4.7，动态对应 4.10；
- 底部「上一条 / 下一条」按当前视图顺序切换（筛选范围内）。
- 抽屉内他人修改实时刷新（WS cell_changed）；编辑中的字段若被他人先行提交，按 4.6 冲突弹窗提示。
- 附件字段在字段区集中预览（缩略图、原图、下载、重命名、删除）。

### 3.4 字段配置面板

- 新增字段：点击末列「＋」→ 弹出类型选择面板（11 种类型，含图标与说明）→ 名称 + 类型配置 → 生效（H-35）。
- 字段右键/表头菜单：重命名（H-36）、复制字段（H-92，复制配置不复制数据）、更改类型（H-38，走影响预览 + 确认）、维护选项（H-40）、删除（H-39，二次确认并警告公式/引用将失效）。
- 字段描述：hover 字段名显示说明文本。
- 选项维护面板：增删改排序（拖拽）、颜色（系统调色板自动分配，可改）、「允许编辑者在录入时添加新选项」开关（**默认关闭**，D14）；删除已使用选项需二次确认（对应记录值清空）。

### 3.5 视图配置面板

| 配置 | 交互规则 |
|---|---|
| 字段显隐 | 可隐藏任意非主字段；隐藏不影响数据，仅影响展示与导出 |
| 冻结列 | 默认冻结主字段；可设置冻结到任意列；水平滚动时固定 |
| 筛选 | 最多 5 条条件，条件间 AND；操作符按字段类型（见 4.5 表）；一键清除 |
| 排序 | 最多 3 级；每级选字段 + 升/降序；空值统一排最后 |
| 分组 | 1 个字段（单选/多选/人员/日期按月/周/日）；组可折叠，组头显示组名与记录数 |
| 行高 | 紧凑 / 中等 / 高 |

所有配置即时保存（H-47）并同步给同视图在线协作者（WS structure_changed）；配置栏按钮展示已启用条件数徽标。字段顺序为表级统一（P0 无视图级列序）。

### 3.6 分享与权限弹窗

- 协作者区：列表展示头像、用户名/显示名、角色、内部/外部标签、来源（显式邀请/链接）（H-63）；添加协作者通过用户名/显示名搜索（H-91；外部人员须已注册）；添加外部协作者角色仅限 可查看/可填写/可编辑（不可授予可管理，D25）；调整角色（H-65）、移除（H-66）；自我保护：不可移除或降级自己，Base 至少保留 1 名可管理者。
- 链接区：分享范围（关闭 / 企业内 / 任何人）+ 链接角色下拉（任何人范围仅出现 可查看 / 可填写）；复制链接；重置链接（旧链立即作废）；关闭分享。范围收窄或关闭后，外部会话 1 分钟内失效（WS session_revoked）。
- 风险提示（动态文案）：
  - 「任何人 + 可填写」：「任何拿到链接并登录的注册用户都可新增记录，但只能看到自己提交的内容」；
  - 「任何人 + 可查看」：「表格全部内容将对所有持链并登录的注册用户可见」；
  - 固定说明：「外部协作者不可导出数据；需要合作方可编辑时，请改用按用户名定向邀请」。

### 3.7 通知中心

全局铃铛打开：未读红点 + 计数（H-74）；列表按时间倒序聚合；点击跳转对应 Base → 记录并定位评论/高亮变化；对象已删除时标注「原记录已删除」不可点击；单条标记已读（H-75）、全部已读（H-76）；通知保留 90 天。

### 3.8 关键交互规范

#### 3.8.1 键盘快捷键（P0）

| 键 | 行为 |
|---|---|
| 方向键 | 移动选中单元格 |
| Enter | 编辑态提交并下移；末行数据区等价触发新增记录 |
| Tab / Shift+Tab | 提交并右移 / 左移 |
| F2 / 双击 | 进入编辑 |
| Esc | 取消本次编辑 |
| Delete | 清空选中单元格 |
| Ctrl/Cmd + Z | 撤销本次会话内最近一步编辑 |
| Ctrl/Cmd + C / V / X | 复制（TSV）/ 粘贴 / 剪切 |
| Ctrl/Cmd + F | 呼出当前视图内搜索 `[前端增强]` |

#### 3.8.2 单元格编辑触发（三通道）

单击选中（不进入编辑态）；双击 / F2 / Enter 进入编辑；选中态下直接打字自动进入编辑 `[前端增强]`。

#### 3.8.3 空态总表

| 场景 | 空态 |
|---|---|
| 空表（有字段无记录） | 插图 + 「从第一行开始」+「导入 Excel」入口 |
| 首次空库（无表） | 新建数据表引导 |
| 筛选无结果 | 「没有符合筛选条件的记录」+ 清除筛选按钮 |
| 分组空组 | 无值记录归入「空」分组，不产生空组 |
| 无评论 | 「围绕这条记录发起讨论，@ 同事及时提醒」 |
| 通知中心 | 「暂无通知」 |
| 与我共享为空 | 引导文案，不堆砌入口 |
| 全部字段被隐藏 | 提示「所有字段均已隐藏」+ 恢复显隐入口 |
| 无权限（403） | 「你没有访问该表格的权限」+ 复制申请人信息按钮 |
| 链接失效 | 「链接已失效」/「表格已被删除」二态 |

#### 3.8.4 错误与异常态

- 统一信封 `{code, message, data}`，code → 中文文案与动作见附录 B；任何写操作失败必须**保留用户输入**并显示可重试状态，禁止「内容消失」。
- 服务端 5xx：顶部轻提示「服务暂时不可用，正在重试」，自动重试 3 次后转手动重试。
- 会话过期（2001）：弹窗引导重新登录，登录后回到原页面；外部账号重新登录后恢复其可访问范围。
- 权限被降级（操作进行中）：下次写请求返回 3001 时前端即时切换为只读态并提示「你的权限已变更」。

#### 3.8.5 保存状态指示

顶栏三态：保存中…（有在途写请求）/ 已保存 / 离线（黄色横幅：「网络已断开，恢复后将自动同步」，见 4.6 离线模型）。长时间未同步（>5 分钟）提示刷新页面，刷新前提供未同步内容清单与复制入口。

## 4. 功能需求

### 4.1 认证与账号（H-01 ~ H-08）

| 项 | 前端需求 |
|---|---|
| 注册 | 用户名 + 密码两大表单；三条归属路径提示文案差异化（企业邀请 / 链接注册 / 直接注册即建企业）；页面固定展示试运行声明 |
| 登录 | 用户名 + 密码；失败展示锁定提示（2002，用户名+IP 联合计次）；无「忘记密码」入口（P0 无密码找回，D16），展示提示「如遗忘密码，账号将无法使用」 |
| 个人信息 | 显示名/头像修改（H-05）、凭旧密码改密（H-06） |
| 注销 | 个人账号自助注销 + 7 天冷静期（H-07），冷静期内可撤回（H-08） |
| 会话 | 过期弹窗引导重登；多标签页多会话独立参与冲突判定 |

### 4.2 首页与 Base 管理（H-21 ~ H-28）

- Base 卡片：名称、表数、最近修改时间/人、星标（星标置顶）；右键/更多菜单：重命名、复制（H-25，评论与历史不复制）、删除（强提示「P0 不可恢复」）、星级切换。
- 企业管理员：成员列表、按用户名邀请（H-10）、停用/启用、角色调整（H-17）、所有者转移二次确认（H-20）、操作审计查询与导出（H-87/H-88）、「任何人」外链清单与强制关闭（H-71/H-72，关闭后通知本 Base 可管理者）。

### 4.3 数据表与字段（H-29 ~ H-40）

#### 数据表管理

- 标签页切换；新增（默认创建表格视图）、重命名、复制（复制结构+数据+视图，不复制评论）、删除（二次确认，Base 内最后一张表不可删）；标签页显示未保存微状态。

#### 字段通用规则

- 主字段：第一列，不可删除/隐藏/拖动；可改名；P0 允许类型：多行文本、数字、单选、公式；其值作为关联/引用显示值。
- 字段宽度可拖拽调整（表级顺序统一，对所有视图生效）。

#### 字段类型矩阵（P0，11 种）

#### 追加规则

- 类型转换（H-38）：按 PRD 7.1 转换规则预览影响（受影响记录数、将清空值），可管理确认后生效；公式/引用/关联三类间不可互转。
- 删除字段（H-39）：二次确认并警告相关公式/引用将失效；依赖引用字段一并提示删除；依赖字段的视图条件自动移除并轻提示。
- 复制字段（H-92）：复制配置不复制数据。

### 4.4 记录编辑（H-48 ~ H-56）

| 能力 | 前端需求 |

| 编辑 | 三通道进入（3.8.2）；Enter 提交下移、Tab 提交右移、Esc 取消；全程无保存按钮 |
| 复制粘贴 | 选区复制为 TSV；单元格级粘贴（单值/单行）；只读列（公式/引用）跳过并在粘贴后提示跳过格数；单选粘贴无匹配选项置空并计入提示；二维区域粘贴/拖拽填充/粘贴自动新增行 → P1（G-5） |

### 4.5 表格视图（H-41 ~ H-48）

- 视图管理：每表至少 1 个视图、默认「表格」视图；可管理/可编辑可新建/重命名/复制/删除；视图对所有协作者可见（P0 无私有视图）；可填写/可查看仅可切换查看。
- 筛选操作符（按字段类型）：文本 包含/不包含/为空/不为空；数字 =/≠/>/</区间/为空；单选 属于/不属于/为空；多选 包含任一/包含全部/为空；日期 等于/早于/晚于/区间/今天/为空；人员 包含/为空；附件 有/无；关联 有关联/无关联；公式 按结果类型。
- 数据加载：游标窗口按需 + 虚拟滚动（ADR 0002）；筛选/排序/分组变更时重置 cursor 全量重拉。
- 空结果按 3.8.3 空态；启用分组后组头记录数、组折叠状态不随他人操作强制改变。
- 视图内搜索 `[前端增强]`：Ctrl+F 在当前视图已加载数据上过滤 + 高亮（详见 ADR 0002 后果）。

#### 保存与冲突

- 自动保存：编辑提交（回车/失焦）即发 UpdateCell（带乐观锁 version），顶栏状态三态（3.8.5）。
- 冲突（4001 版本冲突，FR-06-3 三动作弹窗，禁止静默覆盖）：
  - 文案：「该单元格已被 [B] 修改为 [新值]」；
  - 动作：① 使用对方的值（放弃我的）② 仍用我的覆盖 ③ 复制我的内容后再决定。
- 4002（记录/字段已被删除）：弹窗说明原因，保留编辑内容可复制；不自动重建。
- 同值归一：两人同时新建同名选项，系统合并为同一选项，前端收到合并结构后不重复展示。

#### 离线模型（D28 / ADR 0002）

| 状态 | 行为 |
|---|---|
| 断网 | 黄色横幅「网络已断开，恢复后将自动同步」；**离线只读**：可浏览已加载数据，不产生新编辑；断网前已提交未送达的编辑在本地排队并标记待同步 |
| 恢复 | 自动重连：先 replay_request（W-07，携带 last_seq）补增量，再顺序重传本地队列；逐条反馈成功/冲突（冲突走三动作弹窗），失败编辑不丢失、可复制 |
| 长时未同步 >5 分钟 | 提示刷新，刷新前给未同步清单与复制入口 |

### 4.7 评论（H-57 ~ H-62）

- 挂载：记录级，在详情抽屉评论区展示与发布；两级结构（评论 + 回复，不支持多级嵌套）。
- 权限：可查看及以上可评论（可填写仅限自己可见的记录）。
- @：一名或多名，候选 = 本 Base 协作者（含外部协作者）；选择器基于协作者列表（H-63）。
- 状态：标记「已解决」（折叠 + 置灰）/「重新打开」；评论区显示「已解决/未解决」计数。
- 删除：删除自己发表的评论（不可恢复）；可管理可删任意。
- 列表联动：记录行内含未解决评论的显示评论图标 + 未读数；P0 以详情抽屉与行内角标为准，无独立评论侧栏成员。
- 移动端可评论（D29）。

### 4.8 通知中心（H-73 ~ H-76）

- 事件来源（FR-08-1 矩阵）：评论被 @、评论被回复、被加为协作者/角色变更/被移除、企业邀请、外链被管理员关闭、导入完成/失败、被停用/所有者转移。
- 交互：3.7 已述；点击跳转 Base → 记录定位评论/高亮；失效对象不可点击。
- 实时性：契约无通知推送通道（G-1），P0 以 30 秒轻轮询 H-74 兜底 + 操作后即时本地更新；站内通知保留 90 天，不提供站外转发。

### 4.9 分享与协作者（H-63 ~ H-72）

- 弹窗结构见 3.6；权限判定前端只做入口显隐与网格过滤（第 5 章），最终以服务端为准。
- 外部协作者：显式角色上限「可编辑」（D25）；一律不渲染导出入口（D13）。
- 会话失效：链接关闭/重置/范围收窄 → 外部会话 1 分钟内失效，靠 WS session_revoked 主动感知 + 请求 403 兜底（3.8.4）。
- 管理员强制关闭外链：本 Base 打开中的受影响会话同样收到 session_revoked；Base 可管理者收到站内通知。

### 4.10 操作历史与恢复（H-55 ~ H-56）

- 入口：详情抽屉「动态」标签页，时间倒序；创建记录为首条；字段级 before/after、操作人、时间；关联建立/解除、附件增删、人员变化均记录；不记录评论与视图配置变更。
- 回滚：任意历史节点「将该字段恢复为此值」（H-56）；公式/引用字段标注「不可回滚」；回滚作为新编辑进入历史链。
- 可见性：可管理/可编辑可见；可填写仅自己创建的记录；可查看不可见（前端隐藏「动态」tab）。
- 保留 90 天；外部协作者的历史条目与创建人标识保留展示。

### 4.11 导入与导出

#### 导入（H-77 / H-93 / H-82 ~ H-84，仅可管理）

两段式向导（不做页面跳转，全程对话框）：

1. 文件选择：.xlsx / .xls / .csv，≤20MB、≤5 万行；.xlsx 多 Sheet 选择（P0 一次一个 Sheet）。
2. 预览与配置（H-93）：首行作为字段名开关（默认开）；逐列：名称可改、类型下拉（自动识别可改、无法识别默认为多行文本）、导入/忽略开关；首列默认成为主字段；无法可靠匹配的值预览中高亮。
3. 确认执行（H-82）：结果在首页生成**新的多维表格**；导入期间标记「导入中」，他人不可访问；完成后站内通知（H-83 状态轮询）。
4. 错误报告：部分行失败不影响成功行；提供行级报告下载（H-84，行号、列名、原值、处理结果）。
5. 失败兜底：文件损坏/加密/超限直接拦截说明；**失败保留预览状态，可改映射重试，不强制重新选文件**。

#### 导出（H-85 ~ H-86，仅内部可管理/可编辑；外部恒无入口）

- 菜单：顶栏「更多 → 导出当前视图」→ 选 .xlsx / .csv（.csv 全文本输出）。
- 范围：遵循当前视图筛选结果、字段显隐与顺序；分组/排序尽量保持（分组以分组列排序体现）。
- 值呈现：公式/引用导出计算值；人员导出显示名（多人逗号）；多选导出选项文本；附件导出文件名列表；日期按字段格式；超链接导出 URL。
- 文件名：`Base名称_数据表名_视图名_YYYYMMDD.{xlsx|csv}`；导出动作进入审计（H-85 幂等 client_request_id）。

### 4.12 移动端浏览器（FR-12，只读）

- 可使用：登录访问（含外部账号）、浏览记录列表（宽卡片流：主字段 + 首行摘要）、切换已有视图、展开记录查看字段值、评论与 @、通知跳转、查看在线协作者与保存状态、附件查看与下载。
- 不可使用（入口隐藏 / 操作引导提示，桌面端完成）：新增/编辑/删除记录、字段/数据表结构管理、视图配置（筛选/排序/分组）、导入导出、复制 Base 等全部写操作（含外部「可填写」的填报）。
- 兼容：iOS Safari 15+、Android Chrome 近两年版本，竖屏为主；经公网 HTTP 访问的安全提示属预期行为。
