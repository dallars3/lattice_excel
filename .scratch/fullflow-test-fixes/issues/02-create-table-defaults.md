# 02: 新建数据表默认结构

**What to build:** 新建数据表后立即拥有默认主字段与默认表格视图，服务端一次事务内保证，任何 API 调用方都拿到一致的可用表；前端现有兜底变为幂等防御。

**Blocked by:** None (can start immediately)

Status: ready-for-agent

- [ ] 新建数据表成功后立即查询字段与视图，各有且仅有 1 条：主字段「标题」（多行文本）、视图「表格」（表格视图）
- [ ] 数据表摘要中的字段数与视图数均为 1
- [ ] 数据表行、默认字段、默认视图在同一事务内创建，任一步失败不留下半张表
- [ ] 前端默认结构兜底保持幂等：检测到已有字段/视图时不重复创建
- [ ] TC-030-01 UI 通过；API 侧新表默认结构断言语义一致
- [ ] 既有新建表、重命名、复制、删除表用例不回归
