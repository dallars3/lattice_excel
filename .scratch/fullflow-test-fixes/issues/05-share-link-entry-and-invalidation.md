# 05: 分享链接访客进入与链接失效

**What to build:** 持分享链接的新访客注册或登录后直接进入对应 Base，并能以链接角色读取数据表、字段、视图与记录；重置或关闭链接后旧 token 立即失效并进入失效页，新链接继续可用。

**Blocked by:** None (can start immediately)

Status: ready-for-agent

- [ ] 匿名访问 `/s/{token}` 跳转注册页并携带 link_token；注册成功后直接进入该 Base 工作台
- [ ] 已登录访客访问 `/s/{token}` 直接进入该 Base；落点与前端规范路由 `/base/{id}` 对齐
- [ ] 无企业归属的链接会话可读取该 Base 的数据表、字段、视图与记录查询，链接角色（可查看/可填写）生效
- [ ] 链接会话访问其它 Base 仍被拒绝；结构写操作仍要求企业成员或可管理角色
- [ ] 失效 token 进入 `/err?kind=share-link-unavailable` 失效页，不再回退首页
- [ ] 重置链接后旧 token 立即失效；关闭链接与管理员强制关闭同样立即失效
- [ ] 网关链接缓存的键包含 token 与链接角色；重置/关闭后旧 token 缓存被清除
- [ ] 新链接继续可用；链接注册用户重新登录后仍可访问该 Base（链接未失效时）
- [ ] TC-130-01/02 通过；外部协作者导出仍返回 3002
- [ ] 接口文档同步 H-95 落点与链接关闭事件载荷；补 ADR 记录外部链接账号的租户边界
