# 04: N2 人员目录并集端点 + 权限裁剪

**What to build:** 人员字段候选目录的聚合口径升级为「Base 外部协作者 ∪ 企业成员 ∪ 所有者」：内部用户调用返回企业全员+协作者并集；外部协作者调用仅返回该 Base 协作者集合（不泄露企业全员名单）。响应形状与现有协作者列表对齐（user_id/username/display_name，显示名缺省回落用户名），前端目录函数只改数据源不改映射逻辑——owner-only 企业的人员字段立即可选所有者与企业成员。

**Blocked by:** 01（测试库隔离护栏）。

**Status:** ready-for-agent

- [ ] owner-only 企业：人员目录含所有者本人（user_id/username/display_name 形状正确）
- [ ] 有企业成员的企业：内部用户目录含全部企业成员（去重：同一人既是所有者又是成员不重复）
- [ ] Base 另有外部协作者时：内部用户目录为协作者∪企业成员并集
- [ ] 外部协作者调用：目录仅含该 Base 协作者集合，不含企业全员名单
- [ ] 网格与抽屉的人员编辑器使用新目录后可选可提交（组件级/MSW 用例），前端映射逻辑零改动
- [ ] 成员被移除后：目录不再包含该成员；存量值渲染沿用既有兜底语义（联动票 04 已建立的口径）
- [ ] Go 集成用例覆盖四种视角（owner-only/有成员/有协作者/外部协作者）；前端 MSW 用例覆盖目录切换
