# 03: N5 公式/引用字段回填（创建/复制/转类型）

**What to build:** 在含存量记录的表上新建、复制公式或引用字段（或把已有字段转成公式/引用类型）后，该表全部记录的新列值被幂等物化——单记录读取与视图查询返回计算/引用值，前端不再出现永久「计算中…」；大表按批次入队推进（单作业事务量可控），重跑不产生重复副作用；转出公式/引用类型时对应物化列按删除字段级联同口径清理。

**Blocked by:** 01（测试库隔离护栏）。

**Status:** ready-for-agent

- [ ] 含存量记录的表新建公式字段后：单记录读取返回该列物化值（不再是空/NULL），前端「计算中…」占位随回填完成消失
- [ ] 更改类型（转公式/转引用）与复制公式字段两条路径同样回填
- [ ] 回填经既有 calc 作业机制入队并幂等：同一字段重复触发不产生重复副作用（作业去重键生效）
- [ ] 大表分批：按记录页切分作业批次，单批次事务量可控（批次大小在票内记录决策依据）
- [ ] 转出公式/引用类型时物化列清理与删除字段级联同口径
- [ ] 回填期间写入互不冲突：存量行随后的正常编辑仍走既有写链重算，不产生版本冲突或覆盖丢失
- [ ] Go 集成用例：建字段→断言存量记录物化值；分批边界（少于一批/多批/空表）；幂等重跑；转类型与清理
- [ ] 前端零改动验证：公式渲染器对回填完成前后的占位/值语义不变（既有用例保持绿）
