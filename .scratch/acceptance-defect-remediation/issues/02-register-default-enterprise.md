# 02: N7 注册自动建企 + 孤立账号补建

**What to build:** 注册时不填企业名称（也无链接令牌）的用户自动获得一家默认企业（名称由用户名派生、符合企业名长度规则），用户与企业同事务落库，会话主体与注册响应携带企业 ID 与所有者角色；此前已注册的孤立账号（有用户无企业）登录/鉴权时幂等补建默认企业。此后空企业名注册的用户进入完整首页（有新建入口与聚合区），auth/me 返回企业 ID 与角色。

**Blocked by:** 01（测试库隔离护栏——本票的 Go 测试需要安全测试库）。

**Status:** ready-for-agent

- [ ] 空企业名注册成功后：auth/me 返回企业 ID 与所有者角色；首页聚合数据可取且前端完整渲染（可含组件级/E2E 任一证明口径）
- [ ] 默认企业名称由用户名派生（超长截断、过短以固定文案兜底），符合既有企业名 2–30 字符约束
- [ ] 孤立账号（用户存在、企业为空）登录/鉴权时幂等补建：二次登录不重复建企
- [ ] 用户名冲突仍返回 1002；限速与注册开关语义不变（注意：默认建企路径是否受注册开关约束，按现有企业名路径同口径处理并在票内记录决策）
- [ ] 带企业名注册与外部协作者（链接令牌）注册两条既有路径行为不变
- [ ] Go 表驱动/集成用例覆盖：空名/带名/链接令牌/孤立账号补建/用户名冲突
