# 02: 下拉编辑器点击选中与提交链修复（BUG-01+BUG-04 网格部分）

**What to build:** 单选下拉点击选项即提交并收起编辑器；多选点击为勾选切换且编辑器保持打开；回车仅在搜索词为空时提交已选集合（有搜索词先匹配/勾选不提交旧集合）；方向键在选项间移动高亮并回车选中；选项按钮按下不夺走输入框焦点、点击不冒泡到单元格；失焦提交一律取编辑器最新草稿。单选/多选/人员/关联四类下拉编辑器统一落地。

**Blocked by:** 01（弹层 portal 化后点击交互才可演示）。

**Status:** ready-for-agent

- [ ] 网格内单选：点击选项后单元格立即显示该选项标签，编辑器收起
- [ ] 网格内多选：连续勾选 ≥2 个选项后失焦/回车，单元格显示全部已选标签
- [ ] 多选搜索框输入选项名+回车：该选项被勾选且编辑器保持打开，不提交旧集合
- [ ] 方向键移动高亮（aria-activedescendant）、回车选中高亮项；Esc 取消不落盘
- [ ] 三键语义（Enter 提交下移/Tab 右移/Shift+Tab 左移）与校验失败不落盘行为不变
- [ ] 挂载级 RTL：真实 focus/blur 链路下点击选项提交成功（补齐现有测试只走键盘路径的缺口）
- [ ] 既有编辑器与网格写链用例全部保持绿
