# M2 前端网格编辑缺陷整改（单选/多选选中 · URL 编辑器 · 表头对齐 · 公式实时性 · 弹层裁剪）

Status: ready-for-agent

## Problem Statement

M2 前端（认证/首页/工作台闭环）交付后，试运行验收中实测发现 6 个网格编辑缺陷，全部已在本地部署栈 GUI 复现并有截图/DOM 几何证据：

1. 单选字段在「维护选项」录入选项后，单元格下拉里点击选项仍无法选中（值不写入）；键盘方向键+回车也无法选中。
2. 超链接（URL）字段单元格编辑时出现两个并排输入框（链接地址+显示文本），窄列内挤压变形。
3. 每行记录最左侧的复选框/展开槽位（64px）在表头行没有对应占位，导致数据列与字段名整体错位 64px。
4. 多选字段在网格内点选即丢失（同缺陷 1 的提交链问题）；在记录详情抽屉中可勾选多个，但切换字段后全部丢失；已存值在选项查不到时直接显示原始选项 ID（长串字符，用户感知为「乱码」）。
5. 公式列不实时更新：修改引用列后公式单元格长期停留「计算中…」，要切到别的界面再回来才刷新；且创建公式字段时不校验表达式，未知函数（如 CONCAT）在字段管理阶段静默通过，逐单元格呈现 #ERROR。
6. 单选/多选的选项列表、日期选择器的日历等弹层被网格单元格的 overflow 裁剪，视觉上不可见或显示不全（实测 240×179px 的日历只露出约 7px）。

## Solution

以「编辑器提交链 + 弹层渲染」两个横切修复为主，配合表头占位对齐、URL 编辑器紧凑化、公式实时性快修与创建校验：

- 四类下拉编辑器（单选/多选/人员/关联）统一修复：点击选项即提交（单选）或勾选保持（多选），点击不再被失焦竞态吞掉；失焦提交一律取编辑器最新草稿；补方向键高亮导航。
- 选项面板/日历/行内错误改经 portal 渲染到文档根节点，脱离单元格裁剪上下文，并做视口边缘翻转。
- 表头行补与数据行同宽的行头占位（可全选时放全选框），冻结列偏移统一计入行头宽度。
- URL 编辑器网格内紧凑为单地址输入，完整双字段编辑保留在记录详情抽屉。
- 记录写链路成功后前端拉取该记录整行刷新缓存，公式/引用列即时更新；公式字段创建/修改时后端校验表达式，未知函数/未知引用直接拒绝。
- 渲染层对已失效选项 ID 显示「已删除的选项」兜底，杜绝乱码；维护选项删除被引用选项时要求确认。

## User Stories

1. As a 表格编辑者, I want 点击单选下拉里的选项后值立即写入单元格并收起编辑器, so that 我不需要知道「输入完整选项名再按回车」这种隐藏操作。
2. As a 表格编辑者, I want 多选下拉支持连续勾选多个选项且编辑器保持打开, so that 一条记录能携带多个标签。
3. As a 表格编辑者, I want 多选编辑器收起（失焦或回车）时已勾选项全部保存, so that 我的勾选不会静默丢失。
4. As a 表格编辑者, I want 重新进入多选编辑时看到已选选项的名称标签, so that 我能确认当前值再增删。
5. As a 表格编辑者, I want 被删除选项的存量值显示「已删除的选项」而不是一串原始 ID, so that 界面不出现乱码。
6. As a 表格编辑者, I want 在网格单元格编辑 URL 时只看到一个地址输入框, so that 窄列内不被双输入框挤压。
7. As a 表格编辑者, I want 在记录详情抽屉编辑 URL 时可同时设置地址与显示文本, so that 完整字段能力不丢失。
8. As a 表格访客, I want 每行数据与字段表头逐列对齐, so that 我能准确读表不串列。
9. As a 表格编辑者, I want 表头行首有与数据行同宽的占位（有权限时含全选复选框）, so that 批量选择与列对齐两不误。
10. As a 表格编辑者, I want 修改单元格后本行公式/引用列立即显示新结果, so that 不必切换页面才能看到更新。
11. As a 表格编辑者, I want 新建记录后公式列立即呈现计算结果, so that 单元格不停留在「计算中…」占位。
12. As a 表格管理员, I want 创建公式字段时表达式使用未知函数/未知引用被拒绝并提示原因, so that 错误在字段管理阶段暴露而不是逐单元格 #ERROR。
13. As a 表格编辑者, I want 选项列表与日历完整浮在单元格上方, so that 我能看到并点选全部候选项。
14. As a 表格编辑者, I want 弹层靠近视口边缘时自动翻转方向, so that 最后一行的下拉也不被截断。
15. As a 键盘用户, I want 方向键在下拉选项中移动高亮、回车选中高亮项, so that 键盘可达在网格编辑成立。
16. As a 键盘用户, I want Esc 始终取消编辑且不落盘, so that 误操作可以无损退出。
17. As a 表格编辑者, I want 记录抽屉切换字段或关闭时在途草稿被提交, so that 抽屉编辑不静默丢数据。
18. As a 表格管理员, I want 删除正被记录引用的选项时收到确认提示, so that 我不会无意制造乱码数据。
19. As a 开发者, I want 上述行为有组件级/挂载级/E2E 三层回归用例, so that 修复不被后续迭代打破。
20. As a 试运行用户, I want 修复后的键盘三键语义（Enter 提交下移/Tab 右移/Shift+Tab 左移/Esc 取消）保持不变, so that 既有操作习惯连贯。

## Implementation Decisions

- **编辑器提交链统一**（单选/多选/人员/关联四类下拉编辑器同改）：选项按钮按下时不夺走输入框焦点、点击不冒泡到单元格；单选点击选项即提交并收起编辑器；多选点击为勾选切换且编辑器保持打开；回车仅在搜索词为空时提交已选集合，有搜索词时先按名称匹配/勾选而不提交。
- **失焦提交缝语义不变**：焦点真正离开编辑器宿主才提交，但提交值必须取编辑器最新草稿（修正现状中提交读到旧草稿的时序缺陷）。
- **记录详情抽屉补失焦提交桥**：切换字段或关闭抽屉前提交在途草稿，与网格区同语义；人员/关联编辑器一并受益。
- **弹层 portal 化**：选项面板/日历/行内错误统一渲染到文档根节点，以触发单元格为锚定位；带最小宽度约束与视口边缘翻转；不依赖编辑单元格的 overflow 行为。
- **表头占位对齐**：表头行首渲染与数据行同宽的行头占位单元（记录可勾选时放全选复选框，否则空占位）；表头与数据行两侧的冻结列 sticky 偏移统一计入行头宽度。
- **URL 编辑器紧凑化**：网格内仅渲染地址输入框，显示文本缺省取地址本身；地址+显示文本的双字段完整编辑保留在记录详情抽屉。
- **公式实时性（快修口径，用户已确认）**：记录写链路（单格更新/批量/新建/撤销删除）成功后，前端拉取该记录整行并 patch 缓存，公式/引用列随之更新；不扩展后端响应结构（proto 响应扩展留待 M3 WS 接线时一并评估）。写路径的重算在服务端同步完成，写后即读必得新值。
- **公式表达式创建校验（后端）**：创建/修改公式字段时校验表达式——未知函数、未知字段引用拒绝并返回参数错误（含原因文案）；合法函数清单以 calc 引擎函数注册表为唯一事实源（注意：连接函数为 CONCATENATE，不存在 CONCAT）；存量字段的 #ERROR 哨兵行为保持不变。
- **渲染兜底去乱码**：选项 ID 在配置中查不到时显示「已删除的选项」（灰色标签样式），单元格渲染与编辑器标签同理；「维护选项」删除正被引用的选项时弹确认提示。
- **键盘导航补齐**：下拉编辑器支持方向键在选项间移动高亮（aria-activedescendant）、回车选中高亮项；既有三键语义与校验失败不落盘行为保持。
- **兼容性红线**：不改变 93 条 HTTP 契约与值编码字典；不改字段类型枚举；不改记录写链的乐观锁/幂等语义。

## Testing Decisions

- **好测试标准**：只测外部行为，不测实现细节——「点击选项后单元格出现该选项标签」「修改标题后本行公式列显示新值」「弹层在滚动容器内完整可见且可点击」「删除选项后旧值显示兜底文案」。
- **四层接缝**（前三层沿用现有体系，第四层为用户确认新增）：
  1. 编辑器组件级 RTL（Vitest，现有编辑器测试文件所在接缝）：键盘提交、点击提交、多选勾选切换、行内错误、Esc 取消。
  2. 网格区/抽屉挂载级 RTL（现有网格写链测试接缝）：真实 focus/blur 链路下点击选项提交、失焦提交取最新草稿、表头与数据行列几何对齐、弹层脱离裁剪容器（断言不在滚动/裁剪祖先内）。
  3. MSW HTTP 边界：写成功后整行拉取的请求编排；公式字段创建校验的错误响应映射为行内提示。
  4. 后端 Go 表驱动：公式表达式校验（未知函数/未知引用/合法表达式/边界空白）。
- **新增 Playwright E2E（用户确认引入）**：在现有 e2e 目录新增整改专项 spec 文件，沿用现有 TC 编号规则与 live stack 运行方式；覆盖验收主线——建字段→维护选项→单元格选择（单选点击/多选连续勾选）→URL 编辑→表头对齐→公式实时更新→弹层完整可见。
- **缺口归因**：现有测试只覆盖键盘路径（jsdom 无真实焦点抢占，点击竞态逃逸），修复必须补「挂载后真实点击选项」与「弹层几何」两类用例。

## Out of Scope

- WS 实时推送接线与后端响应结构扩展（M3 评估；跨客户端实时协作随之解决）。
- 跨行依赖公式的增量重算推送；批量粘贴/填充触发的公式刷新（沿用既有写链语义）。
- 暗色主题与 i18n（方案既定延后项）。
- 移动端布局适配。
- 人员/关联字段候选数据加载性能优化（本次只修提交链与弹层）。
