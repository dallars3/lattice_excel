# 06: 离线队列 store 状态机（ADR 0002 语义）

**What to build:** 离线编辑的队列状态机（纯 store，M1 不与真网络联动）：断线只读、在途编辑保留入队、重连后先补增量再顺序重放、冲突转三动作裁决、任何失败项内容不丢失可复制、滞留超 5 分钟触发未同步清单提示流。语义来自 ADR 0002 与需求文档 4.6 离线模型。

**Blocked by:** 01: 工程底座

**Status:** ready-for-agent

- [ ] 全状态迁移表驱动测试绿（入队/断线只读/重放中/冲突/全部完成/滞留）
- [ ] 断线状态下新编辑被拒（离线只读），已入队项保留
- [ ] 冲突项可被转交三动作裁决（use_other/overwrite/copy），失败项内容可复制不丢失
- [ ] 队首滞留超 5 分钟触发「未同步清单 + 复制入口」提示流（计时器可注入）
- [ ] 多标签各自独立队列（store 实例隔离语义可测）
