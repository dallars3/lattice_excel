# 03: 邀请流语义修复（N7 收尾）

**What to build:** 注册自动建企（N7）落地后，企业成员邀请流对几乎所有用户失效（新注册用户必然已自有企业，而邀请/接受的前置是「用户无企业归属」）。修复为：按用户名可邀请任何活跃用户；接受邀请即为目标企业新增成员行（角色按邀请授予），**不修改用户的企业字段、不迁移不清空既有 Base**；企业内鉴权按成员行判定。实现票必须先验证现有鉴权链在「用户以成员行归属（非当前企业字段）」场景下对目标企业 Base 的访问是否成立，不成立则修正鉴权。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 移除邀请与接受两处「目标用户须无企业归属」前置，允许邀请任何活跃用户
- [ ] 接受邀请 = 目标企业新增成员行（角色按邀请授予），不修改用户企业字段、不迁移既有 Base、不破坏自有数据访问
- [ ] 实现前先验证跨企业鉴权链：用户以成员行归属访问目标企业 Base 是否成立，不成立则修正为企业内鉴权按成员行判定（验证过程记录）
- [ ] Go 集成用例：邀请自有企业用户→接受→以成员身份访问目标企业 Base 全链路
- [ ] 重复接受幂等（同一用户同一企业不重复建成员行）；外部协作者（链接令牌）路径行为不变
- [ ] 既有成员生命周期用例回归绿（含此前改直建孤立账号的夹具，可按新语义简化）
