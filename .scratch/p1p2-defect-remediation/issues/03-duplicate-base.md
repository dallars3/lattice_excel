# 03: 复制 Base 端到端

**What to build:** 用户复制多维表格（H-25）时得到包含全部数据表、字段、选项、视图与记录的副本；评论、历史、审计不复制；任一表复制失败时不留下半成品 Base。对应缺陷 #11。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 复制含 2 张表、多字段、多视图、多条记录的 Base，副本结构与数据与源一致。
- [ ] 副本评论数为 0，编辑历史不复制。
- [ ] 复制失败路径回滚，首页列表不出现半成品副本。
- [ ] 建立可复用的记录行复制能力，供复制数据表复用。
