# 06: 记录写入（新增·编辑·批量·删除·撤销·冲突）

**What to build:** 用户能在网格里真正维护数据：三种入口新增记录（底栏按钮、末行方向下键、首行幽灵行），四种通道进入编辑（双击、F2、Enter、直接打字），Enter/Tab 提交并移动、Esc 取消不落盘；提交后本地立即生效并在失败时保留输入；发生版本冲突时按三动作裁决；支持选区 TSV 复制与单值/单行粘贴并报告跳过格数；支持勾选行批量删除、复制记录、7 秒内撤销删除、会话内 Ctrl+Z 撤销；无排序视图下可拖行手动排序。

**Blocked by:** 05（记录读取与 11 类单元格渲染）

**Status:** ready-for-agent

- [ ] 底栏「+ 新增记录」、末行方向下键、首行幽灵行三条入口都能创建记录，创建后焦点落在主字段并进入编辑
- [ ] 双击、F2、Enter、直接打字四种通道进入编辑；单击仅选中不进入编辑
- [ ] Enter 提交并下移、Tab 提交并右移、Shift+Tab 左移、Esc 取消不落盘；提交期间顶栏呈「保存中」
- [ ] 提交成功后本地立即应用并记录版本；失败保留输入、显示行内错误并可重试
- [ ] 4001 冲突弹窗展示对方新值与三动作（采用对方 / 仍用我的覆盖 / 复制我的内容），不静默覆盖
- [ ] 4002 记录或字段已删除时弹窗说明并保留可复制内容，不自动重建
- [ ] 选区复制为 TSV；单值与单行粘贴经批量接口落库，只读列跳过与选项不匹配置空分别计入提示
- [ ] 勾选一行或多行可批量删除（二次确认）与复制记录（读+建组合，不复制评论与历史）
- [ ] 删除后底栏浮出「已删除 n 条 [撤销]」并保留 7 秒，撤销后数据恢复；超时入口消失
- [ ] Ctrl/Cmd+Z 撤销本次会话内最近一步编辑，刷新后不可撤销
- [ ] 视图无排序与分组时可拖行手动排序；有排序/分组时拖行被禁止并提示「当前为排序视图」
- [ ] 达到单表 5 万行上限时新增被拒并提示联系管理者
- [ ] 组件测试经 MSW 覆盖新增/编辑/提交/冲突/删除撤销/批量粘贴/拖行约束；补偿逻辑（撤销与乐观回滚）以纯逻辑单测覆盖
