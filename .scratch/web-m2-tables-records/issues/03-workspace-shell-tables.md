# 03: Base 工作台骨架与数据表管理

**What to build:** 从首页进入某个 Base 后，看到与需求一致的五段式工作台：顶栏（Base 名称、保存状态位、在线头像位、分享入口位、更多菜单）、表与视图栏、网格区、底栏。用户能在表标签之间切换，并新建、重命名、复制、删除数据表；最后一张表禁止删除。有在途写请求时表标签显示「保存中」微状态。本票只交付骨架与表结构管理，网格数据与视图切换由后续票接线。

**Blocked by:** 02（首页 Base 聚合与 Base 管理）

**Status:** ready-for-agent

- [ ] 通过深链进入 Base 时按地址加载 Base 信息、表列表与默认视图，页面呈五段式布局
- [ ] 表标签页展示全部数据表并切换当前表；切换后视图栏与网格区跟随当前表
- [ ] 新建表（1–30 字符、同 Base 重名返回冲突提示）后自动切换为当前表
- [ ] 重命名、复制、删除表可用；仅剩一张表时删除入口禁用；删除需二次确认
- [ ] 顶栏「更多」按角色提供重命名/复制/删除/星标，删除为强提示二次确认
- [ ] 存在在途写请求时当前表标签显示「保存中」，结束后恢复
- [ ] 底栏展示「+ 新增记录」入口位置与记录数占位，网格区在无数据票时呈骨架空态
- [ ] 组件测试经 MSW 覆盖表列表加载、表 CRUD、最后一张表禁删与深链进入
