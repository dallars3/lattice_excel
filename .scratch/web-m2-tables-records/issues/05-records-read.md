# 05: 记录读取与 11 类单元格渲染

**What to build:** 打开工作台后网格能按当前表与当前视图加载真实记录，并随滚动按游标继续取页；11 种字段类型按各自规则正确显示值。没有记录、筛选无结果、全部字段被隐藏、加载失败时都有明确空态或错误态。底栏展示已加载记录数。

**Blocked by:** 04（字段结构管理与字段面板）

**Status:** ready-for-agent

- [ ] 记录查询携带表与视图标识，按游标与 20/100 条限制取页；滚动到已加载区间末尾时自动取下一页
- [ ] 网格纵向虚拟滚动复用既有窗口计算，滚动过程不出现整表重渲染卡顿
- [ ] 多行文本单行省略且悬停可见全文；数字按字段格式渲染（千分位/百分比/货币、0–4 位小数）且空值与 0 显示不同
- [ ] 单选与多选渲染带颜色的选项标签；日期按三种格式渲染；人员渲染头像与显示名（多人并列、停用成员灰显）
- [ ] 附件渲染文件名与缩略图；超链接渲染显示文本并在新窗口打开（编辑态不跳转）
- [ ] 公式渲染计算结果，计算中显示占位，错误值渲染 `#ERROR` 且悬停显示原因；关联渲染目标记录主字段值并可跳转；引用按被引用字段类型渲染，多条并列
- [ ] 空表、筛选无结果、全部字段被隐藏、请求失败四类场景各呈约定空态/错误态，写失败不丢内容
- [ ] 底栏展示「已加载 n 条」，仍有下一页时显示「n+」；不展示虚构的总数
- [ ] 组件测试经 MSW 覆盖游标分页、各类渲染器取值边界与四类空态/错误态
