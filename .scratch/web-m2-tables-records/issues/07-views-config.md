# 07: 视图管理与全量视图配置

**What to build:** 用户能管理视图并真正用视图改变数据呈现：新建、重命名、复制、删除视图（每表至少保留一个）；通过面板设置最多 5 条 AND 筛选（操作符按字段类型给出）、最多 3 级排序（空值排最后）、单字段分组并折叠、字段显隐、冻结列、三档行高与字段宽度拖拽。所有配置即时保存为全量替换，工具栏按钮显示已启用条件数徽标；条件变更时游标重置并全量重拉。

**Blocked by:** 05（记录读取与 11 类单元格渲染）

**Status:** ready-for-agent

- [ ] 视图列表可切换；新建（1–30 字符、同表不可重名）、重命名、复制、删除可用；仅剩一个视图时删除入口禁用
- [ ] 筛选最多 5 条且条件间为 AND，第 6 条被拒并提示上限；操作符按字段类型白名单给出（文本/数字/单选/多选/日期/人员/附件/关联/公式）
- [ ] 排序最多 3 级、每级可选升降序，空值统一排最后；第 4 级被拒并提示
- [ ] 分组仅支持单字段（单选/多选/人员/日期按日/周/月），组可折叠，组头仅显示组名与折叠控件、不显示全量记录数（按 N1 裁定）
- [ ] 可隐藏任意非主字段、设置冻结到任意列、切换紧凑/中等/宽松行高；字段宽度可拖拽且限制 40–2000px
- [ ] 所有配置改动即时提交全量视图配置并成功回读；工具栏按钮显示已启用筛选/排序/分组条件数
- [ ] 筛选、排序、分组变更后清空已加载区间并从首个游标重拉，不拼接旧条件的数据
- [ ] 全部字段被隐藏时提示「所有字段均已隐藏」并提供恢复显隐入口
- [ ] 筛选无结果时展示空态与清除筛选按钮
- [ ] 组件测试经 MSW 覆盖视图 CRUD、配置上限、即时保存载荷、条件变更重置游标、组头无计数与宽度持久化
