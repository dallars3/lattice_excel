# 01: 认证闭环（注册·登录·登出·会话守卫）

**What to build:** 让浏览器里的真实用户能完成注册与登录并拿到会话：直接建企业的普通注册、凭企业邀请的注册、凭分享链接的注册三条路径都要可用且有差异化文案；登录成功进入首页（带 next 参数时回到原页面）；任意接口返回会话失效时统一弹重登并以原页面为返回目标；登出后清空会话与本地缓存。登录页、注册页、首页固定展示试运行免责声明。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 注册表单校验用户名（4–20 位、字母开头、字母/数字/下划线）与密码（8–32 位、须含字母与数字），非法时不发请求并给出字段级文案
- [ ] 企业名称为可选输入，且仅在既无邀请也无 link_token 时出现；三条路径各有差异化归属提示
- [ ] 服务端 1002（用户名已存在）与 1001（参数非法）以行内错误呈现，已填内容不丢失
- [ ] 登录成功写入同源 Cookie 会话并跳转首页；存在 next 参数时返回该路径
- [ ] 登录失败按 2002 显示锁定/失败提示，并固定展示「如遗忘密码，账号将无法使用」，页面不提供找回入口
- [ ] 任意接口回包 2001 时弹重登弹窗，重登成功后回到原页面；登出清空服务端状态缓存与编辑态
- [ ] 登录/注册/首页三处均渲染同一条试运行声明文案
- [ ] 组件测试经 MSW 覆盖 1001/1002/2001/2002 四条路径与三条注册路径的文案差异
