# 09: 权限矩阵与异常态收口

**What to build:** 把需求第 5 章的四级角色 × 内部/外部矩阵在所有已落地入口上逐项核对并补齐显隐/只读/仅自己三态，使可管理、可编辑、可填写、可查看四种身份在使用同一应用时看到各自应当看到的能力；同时把跨页面的异常态收敛成统一行为：权限中途被降级立即转只读、服务端 5xx 自动重试三次后转手动、保存状态三态、断网横幅占位、容量与空态矩阵。

**Blocked by:** 06（记录写入）、07（视图管理与全量视图配置）、08（记录详情抽屉与附件字段）

**Status:** ready-for-agent

- [ ] 可管理：字段与表结构入口、表头全项菜单、分享入口位、顶栏「更多」全项均可见可用
- [ ] 可编辑：可编辑单元格与视图配置，但字段删除与类型转换入口隐藏；顶栏重命名/复制/删除入口隐藏
- [ ] 可填写：网格只展示本人创建的记录并在页眉提示「仅显示你创建的记录」；只能编辑自己的记录；新增入口可见而删除、批量条、导入导出、结构入口隐藏
- [ ] 可查看：全部数据只读，新增/删除/编辑入口隐藏；可切换已有视图但不可改配置
- [ ] 外部账号：无论角色均不渲染导出入口；首页不出现新建入口
- [ ] 任意写请求返回 3001 时立即切换为只读态并提示「你的权限已变更」，不使用前端显隐作为安全边界
- [ ] 服务端 5xx 自动重试三次后转手动重试并提示；9001 有兜底文案
- [ ] 保存状态三态（保存中/已保存/离线）在顶栏正确切换；断网时展示黄色横幅占位，不做本地排队重放（留 M3）
- [ ] 容量上限（表 50、字段 100、记录 50,000、筛选 5、排序 3）与各错误码均落到约定提示
- [ ] 权限矩阵以快照测试覆盖四角色 × 内部/外部 × 关键入口，3001/5001/9001 各有组件用例
- [ ] 手动在浏览器按四种角色走查一遍工作台，确认无越权入口、无只读态下仍可编辑的漏点
