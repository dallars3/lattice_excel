# 02: 首页 Base 聚合与 Base 管理（含权限门基座）

**What to build:** 登录用户在首页能看到自己全部可访问的 Base 并按「最近访问 / 我创建的 / 与我共享 / 星标」分区浏览；能按名称搜索、新建 Base 并直接进入工作台；能在卡片上重命名、复制、删除（强提示不可恢复）、切换星标。外部账号首页不出现任何新建入口。本票同时落地统一的权限门基座（由 Base 的 my_role 与内部/外部身份归一成 close/hide/readonly/filter-self 四类 UI 态），供后续票复用。

**Blocked by:** 01（认证闭环）

**Status:** ready-for-agent

- [ ] 首页按聚合接口渲染四个分区，星标区置顶；卡片展示名称、表数、最近修改时间与修改人、星标状态
- [ ] 名称搜索输入 1–50 字符即可过滤并展示结果；无结果与「与我共享为空」有克制空态
- [ ] 新建多维表格成功后直接进入该 Base 工作台；未命名时使用默认名称
- [ ] 卡片菜单可重命名（1–50 字符）、复制（不复制评论与历史）、删除（「P0 不可恢复」二次确认）、切换星标
- [ ] 外部账号首页隐藏新建入口与任何 Base 级管理入口
- [ ] 权限门基座可据 Base 的 my_role 与 internal/external 输出四类 UI 态，并有一个入口经它渲染显隐
- [ ] 组件测试经 MSW 覆盖聚合渲染、搜索、新建、重命名/复制/删除/星标与外部账号首页
