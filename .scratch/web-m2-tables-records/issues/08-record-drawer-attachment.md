# 08: 记录详情抽屉与附件字段

**What to build:** 用户点击行首展开按钮后，右侧出现记录详情抽屉，可在顶部编辑主字段，并按字段顺序查看与编辑当前视图隐藏字段在内的全部字段（公式与引用只读并标注）；可用「上一条 / 下一条」按当前视图顺序切换；附件字段在抽屉内可预览缩略图、上传、下载、重命名、删除。抽屉展开时网格仍可交互。

**Blocked by:** 06（记录写入）

**Status:** ready-for-agent

- [ ] 点击行首展开按钮打开右侧抽屉（约 480px），不遮挡网格交互；关闭后回到网格原选中位置
- [ ] 抽屉顶部主字段可编辑，字段区按字段顺序展示全部字段（含当前视图隐藏字段）
- [ ] 公式与引用字段在抽屉内只读并有明确标注
- [ ] 「上一条 / 下一条」按当前视图顺序切换；目标不在已加载区间时自动补拉后再切换
- [ ] 附件字段可上传（单文件 ≤20MB、单记录 ≤10 个，超限或黑名单拦截有提示）、下载、重命名、删除，并展示缩略图
- [ ] 抽屉内编辑沿用同一提交与冲突语义，失败保留输入
- [ ] 组件测试经 MSW 覆盖抽屉打开/关闭、全字段渲染、上下条切换（含补拉）、附件增删改与超限提示
