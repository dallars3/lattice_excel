# 04: 字段结构管理与字段面板

**What to build:** 用户在表头看到按位置排列的字段，主字段固定第一列且不可隐藏、删除、拖动；可管理角色能从末列「＋」新增 11 种字段类型中的任意一种，并为其配置类型专有参数；可重命名字段、查看悬停描述、复制字段（仅配置）、在类型转换前看到影响预览、在删除字段前看到影响面确认。选项类字段可维护选项（增删改、排序、颜色、允许录入时新建开关）。

**Blocked by:** 03（Base 工作台骨架与数据表管理）

**Status:** ready-for-agent

- [ ] 表头按字段 position 渲染；主字段固定第一列，隐藏/删除/拖动入口对其均不可用，其类型仅限多行文本/数字/单选/公式
- [ ] 新增字段可选择 11 种类型，名称 1–30 字符且同表内不可重名；描述 ≤500 字符并在悬停表头时显示
- [ ] 字段配置面板可按类型编辑：数字（整数/小数 0–4 位/百分比/货币/千分位）、日期（是否含时间与三种格式）、人员（是否多选）、单选与多选（选项列表 + 允许录入新建，默认关闭）、公式（表达式）、关联（目标表与是否多条）、引用（关联字段 + 目标字段）
- [ ] 更改字段类型前先展示受影响记录数与将清空值数量，确认后生效；公式/关联/引用三类字段不提供互转入口
- [ ] 删除字段前展示记录数、依赖公式数、依赖引用数并二次确认；被视图条件引用的字段删除后条件自动移除并有轻提示
- [ ] 复制字段仅复制配置不复制数据
- [ ] 选项维护支持增删改与拖拽排序、调色板自动分配且可改色；删除已使用选项需二次确认；允许录入新建关闭时，录入无匹配选项提示「联系表格管理员添加」且不可新建
- [ ] 字段数达到 100 上限时新增被拒并提示容量上限
- [ ] 组件测试经 MSW 覆盖新增、重命名、配置、转换预览、删除影响面、复制、选项维护与 5001 上限
