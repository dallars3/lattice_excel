## 1. 执行过程与环境事件

1. 首轮执行时发现部署中的 `excel-worker-service` 进程已退出且未自动恢复；已用 detached 方式重启并确认 `/readyz` 恢复 200。
2. 执行 `TC-140-03`（.xls 导入）时 worker 触发 panic 退出（`extrame/xls` / `ole2.OpenFile` 空指针），导致后续所有 worker 依赖接口返回 9001。已确认根因并在最后一轮把该用例移到末尾，避免污染其余结果（缺陷 #10）。
3. 每轮执行前/后均核对 `/healthz`、`/readyz` 与三进程状态；除上述 xls 外未再出现进程级异常。

## 7. 口径与备注

- 本轮结论以「部署后 HTTP/WS 黑盒边界」为准；包级测试不在本轮范围。
- 部分 UI 用例因自动化交互（多选/人员/关联编辑器在自动化下偶发打开后立即关闭）无法稳定执行，已在报告中标注为 BLOCKED，不计为产品缺陷；对应服务端语义由 API 用例覆盖。
- 审计/通知为异步链路，用例内已做最长 20s 的轮询等待。
- 注册/登录有限速（10/min、20/min）；自动化已内置 5003 等待重试。
