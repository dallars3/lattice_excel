# 首页缺少通知铃铛与用户信息

Status: needs-triage
Severity: P0
Source: TC-010-04（UI 冒烟）

## 复现步骤

1. 打开 `http://127.0.0.1:8080/login`，用合法账号登录。
2. 进入 `/home` 后检查顶栏。

## 实际

- 顶栏只有标题「协作多维表格」与「退出登录」按钮。
- 不存在通知铃铛入口，也不展示当前用户信息（用户名/头像）。

## 期望

按 TC-010-04：登录成功后进入首页，顶栏通知铃铛与用户信息可见。

## 证据

- Playwright：`web/e2e/p0.spec.ts` → `TC-010-04 | 登录成功`
- 失败断言：`getByRole('button', { name: /通知/ })` 5s 内未找到元素；`getByText(OWNER)` 亦无命中。
- 错误上下文：`web/test-results/p0-TC-010-04-登录成功/error-context.md`

## 影响

P0 冒烟失败；首页缺少全局通知与身份信息入口，通知中心（M4）也缺少落点。若判定 M4 前不阻塞，需要明确降级口径并更新用例预期。
