## 2. 里程碑边界（本轮可测范围声明）

前端 M2 交付了「注册 → 登录 → 首页 → Base 工作台（表/字段/视图/记录）→ 详情抽屉与附件」的 UI 闭环；**实时协作 UI、冲突三动作弹窗、离线横幅、评论界面、通知中心、分享弹窗、导入导出向导、移动端专属 UI 属 M3~M5**。因此：

- 标注 `UI` 的用例在浏览器中人工/自动化执行；
- 标注 `API` 的用例经 HTTP 直调（curl/脚本）验证服务端语义——其中不少 AC 的「UI 半边」留待对应里程碑验收，本联调用例只锁服务端行为与契约；
- 标注 `WS` 的用例用双连接脚本（wscat/自写客户端）走协议级对测；
- 标注 `PERF`/`COMPAT` 的见 T17。

## 3. 优先级定义

| 级别 | 定义 | 失败处理 |
|---|---|---|
| **P0** | 核心闭环与数据/资金安全：登录注册、建 Base→表→字段→记录主链路、主字段保护、会话、服务端权限拒绝、数据正确性与不丢失、部署可达。任一失败 = 阻塞发布 | 立即停测、开缺陷、修复后回归 |
| **P1** | 重要功能与健壮性：11 种字段类型细节、视图配置全量、批量/幂等、导入导出、评论/通知/分享/审计 API 语义、错误码场景、WS 广播语义 | 记缺陷，当轮排期修复；累计 >3 个 P1 失败同样阻塞 |
| **P2** | 体验细节、边界值、性能预算、兼容矩阵、埋点、合规展示 | 记缺陷，评估后可 wontfix/后置 |

冒烟集 = 全部 P0（约 45 条），新部署先跑冒烟再进 P1/P2。
